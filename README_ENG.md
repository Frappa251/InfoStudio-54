## 🍸 Welcome to InfoStudio-54
**InfoStudio-54** is not just the most exclusive club in town, but also a software project developed to provide a smooth and premium digital experience for our clients.

This repository contains the entire source code of the web platform: from a *glassmorphism* and neon style frontend to a solid backend that manages the heart of the venue.

## 💻 What does this code do? (Core Features)
The system is designed to automate and manage interactions with customers:

* 🎟️ **Reservation Management:** Users can select the date, number of people, and table type (Standard, Premium, VIP).
* 🍾 **Digital Menu & Orders (JSON):** An interactive menu with filters for drinks and bottles. Orders are processed and sent directly using JSON formats.
* 👑 **VIP Area (Auth):** Registration and Login system for access to a private dashboard with a "Digital Card".
* 💾 **Persistent Storage:** All data (users, reservations, logos) are stored securely in a local relational database.

## 🛠️ Technologies Used
The project was migrated from a BaaS architecture (Supabase) to a local server infrastructure managed entirely by us.

**Frontend:**
* `HTML5` & `CSS3` (Custom style, CSS animations, responsive layout)
* `JavaScript` (Vanilla JS & `jQuery` for AJAX calls)

**Backend & Database:**
* `PHP` (RESTful API for frontend request management)
* `MariaDB` / `MySQL` (Relational database for users and reservations)
* `phpMyAdmin` (For database administration)
* `JSON` (Data interchange format between client and server)

Since the project uses PHP and a database, simply opening the HTML files in the browser is not enough. You need to configure a local server (like XAMPP on Windows or native tools on Linux/Fedora).
